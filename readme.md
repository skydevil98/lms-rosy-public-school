## Mini Projects

### 1. Snake Game (`/snake-game`)
A minimal Python implementation of the classic Snake Game using the built-in `tkinter` library. Requires zero external dependencies. To play, navigate to the repo root and run:
`python3 snake-game/snake.py`

*Future mini-projects will be added in their respective standalone folders.*
